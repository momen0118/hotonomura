# 穂戸野村(仮題)

設計は `SPEC.md`。作業の約束事は `CLAUDE.md`。Fable への質問は `FABLE_QUESTIONS.md`。

いまできているのは **1日目〜14日目(一周が通しで閉じました)**と、**巻き戻し→出発の朝→次の周**、そして**日記の積層(一冊・日付固定・書き足し・遺構黒塗り)・二周目の開幕・祠の発見と捧げと焼き(一晩一件・納税制)・商店の奥の棚・タロの生死と世界同期・堤防とツリさんと餌の台詞・花火・ナツの昔話**です。さらに **イベント依存ツリー**(親の思い出を失った周は配下のイベントが丸ごと起きない——祭りは1周目に収穫されると二度と起きず、集会所の写真だけが残る)と、**村産小物**(祠で差し出せる村の水の実物)、そして **ED三枚**——**捧げて帰るED**(祠で実物を差し出して鳥居を抜ける)・**空っぽED**(村の思い出を失いきる)・**ナツED**(3周目以降、ナツの家でノートを読まずにいた周に開く)——が入りました。物語としては一通り閉じています。

## どうやって動かすか

遊ぶだけなら、このリンクを開けば動きます。何もインストールしなくていいです。スマホでも遊べます。

**https://momen0118.github.io/hotonomura/**

これは GitHub Pages(GitHub が無料でくれる、静的サイトの置き場)です。`docs/index.html`(1枚に固めた完成品)をそのまま配っています。

- GitHub の設定は一度だけ: **Settings → Pages → Build and deployment → Source を「Deploy from a branch」、Branch を `main` の `/docs` にして Save**。数分で上のURLで遊べるようになります。
- 中身を更新したいときは、ターミナルで `npm run pages` を実行 → `docs/index.html` が新しくなる → コミットして push。それで上のリンクの中身が入れ替わります(反映まで数分)。

自分のPCで動かしたいときだけ、下を使ってください(ターミナル=黒い画面にコマンドを打つやつ)。

```bash
npm install        # 最初の一回だけ。必要な部品をダウンロードする
npm run dev        # 開発サーバーを起動。表示されたURLをブラウザで開く
```

`npm run dev` を動かしたまま JSON を書き換えると、ブラウザが勝手に読み直します。保存するたびに画面が更新されるので、台詞の調整はこれが速いです。止めるときは `Ctrl + C`。

その他のコマンド:

```bash
npm run build      # 配布用に1枚のHTMLへ固める(dist/index.html)
npm run artifact   # 上に加えて、リンク公開用の形に整える(dist/artifact.html)
npm run check      # 型の間違いがないか調べる
node scripts/smoke.mjs        # 一周目〜二周目を自動で通し、日記の行数・黒塗り・破れページ・JSエラーを確かめる
node scripts/format-data.mjs  # src/data の JSON を読みやすい形に整える
node scripts/bg-preview.mjs   # 背景を一覧の画像にして書き出す
```

## どこを書き換えると、なにが変わるか

**台詞やイベントを直すときは `src/data/` の中だけ見れば足ります。** プログラム側(`src/core`, `src/screens`)は触らなくて大丈夫です。

| ファイル | 中身 |
|---|---|
| `src/data/items.json` | 持ち物9品。名前と一行説明。`fixed: true` は外せない品(スマホ) |
| `src/data/places.json` | 場所。`label` が場所選択ボタンの文言(行動形) |
| `src/data/days.json` | 何日目のどのコマで、どこへ行けるか。`festival: true` はコマ制を崩すイベント回 |
| `src/data/stalls.json` | 祭りの屋台と値段 |
| `src/data/events/op.json` | OP(出発の朝) |
| `src/data/events/day01.json` 〜 | 日ごとの固定イベント(台詞の本体) |
| `src/data/events/ambient.json` | 場所ごとの日常イベント(日によって揺らぐやつ) |
| `src/data/tags.json` | 捧げられる対象の名前(確認用パネルに出る) |
| `src/data/weights.json` | 思い出の重み。帰りのバスで重い順に収穫される |
| `src/data/names.json` | 固有名の差し込み表。決まったらここだけ直せば全域に反映される |

### イベントの書き方

1行が1つの表示になります。

```json
{ "n": "縁側に座る。蚊取り線香のにおい。" }        地の文
{ "c": "ナツ", "t": "週3?! 夏休みなのに?" }        台詞(鉤括弧は出しません)
{ "c": "{{name}}", "t": "距離ちか・・", "thought": true }   心の声
{ "bg": "river" }                                  背景の切り替え
{ "diary": { "fact": "…", "feeling": "…" } }       その日の日記に一行足す(下を参照)
{ "photo": { "id": "…", "caption": "…", "tags": ["taro"] } }  その日の写真
{ "here": "商店裏" }                                画面上部の現在地表示を変える
{ "include": "shop_intro" }                        別のイベントの中身をここに差し込む
{ "roll": { "flag": "hit", "chance": 0.5 } }       くじを引いてフラグを立てる
{ "money": 3000 }                                  所持金を増減する
{ "if": "item:game", "n": "…" }                    ゲーム機を持っているときだけ出す
{ "if": "lost:taro", "n": "…" }                    タロを捧げたあとだけ出す
{ "if": "day>=8", "n": "…" }                       8日目以降だけ出す
{ "if": "loop>=2", "n": "…" }                      二周目以降だけ出す
{ "if": "natsu_today", "n": "…" }                  その日ナツがいるときだけ出す(!natsu_today で不在の日)
{ "if": "loop>=3 && !shelf_seen", "n": "…" }       「かつ」でつなげる(調査導線の解禁など)
{ "unlock": ["river"] }                            場所を解放する
{ "comment": "…" }                                 表示されない覚え書き
```

イベントの `kind` は3種類です。

- `fixed` … その日のそのコマの固定イベント
- `ambient` … その場所の日常イベント。同じ弾は2日あけて出る
- `prelude` … コマの本編の手前に差し込む断片(体の記憶の空振りなど)

- `{{name}}` は主人公の名前に、`{{grandpa}}` などは `names.json` の名前に置き換わります。
- `"draft": true` を付けた行には、画面に赤い「仮」の印が出ます。**Fable の確定稿待ち、という意味です。** 確定稿が入ったら消してください。
- 選択肢は `"choice"` の中に `"lines"` を入れ子にします(`day02.json` のラムネ/アイスが見本)。

### 日記の一行は、事実と感情に分かれている

「日記の文法」(FABLE_ANSWERS.md)をそのままデータの形にしてあります。

```json
{ "diary": {
    "fact": "商店でコーラを買ったら、おばちゃんがおまけしてくれた。",
    "feeling": "距離が近い。",
    "tags": ["fun:cola"],
    "lost": "redact"
} }
```

- **`fact`(事実文)** … 供物の名前はここにだけ書く。タグもここに付く
- **`feeling`(感情文)** … タグも代名詞も持たない。**黒塗りのあとも残る**
- **`blackout`** … 捧げられたときに■で潰す文字列。**推論しないので、必ず書く**
  - たこ焼き型(物・体験) … 対象語だけ。「川で■■をつかまえた。」
  - 生き物型(生き物・人との関係) … 名前+種別まで。「■■■■■■になつかれた。」

**行は消しません。日は縮みません。**黒の面積が重さを語ります。

### 帰りのバスの「収穫」

思い出には `weights.json` で重みが付いています。帰りのバスに乗ると、**神が村の思い出を勝手に「収穫」します**。UIも演出も出ません。気づくのは、二周目以降に日記を開いたときだけです。

収穫は**納税制**です。各周のノルマ = `5 × 周回数`(`weights.json` の `_tax_per_loop` で調整)。祠で焼いたページの重みはノルマに充当され、帰りのバスでは**不足分だけ**を最上位の重み帯からランダムに収穫します。焼き過ぎの繰り越しはありません。1周目だけは例外で、収穫は祭りの一件で固定です(選べない・無音・不可避——祠の対になる手触り)。

**この収穫を止めることはできません。**外から持ってきた実物(スマホ以外の持ち物)を**祠で自分から差し出したときだけ**、帰り道がひらきます。祠では日記のページを焼くこともできます(焼いた分はノルマに充当されますが、出口は開きません——自分の畑の作物で家賃は払えない)。

### tags がいちばん大事

すべての行・日記・写真・場所・持ち物に `tags` を付けられます。
**そのタグが「捧げられた」瞬間に、そのタグを持つものが世界からも日記からも一斉に欠けます**(SPEC §3)。

- 世界からは消える(その台詞は起きなかったことになる)
- 日記では黒く塗られる(消さない。欠けが見えることが痛みの本体だから)
- 写真は糊の跡と四つ角の日焼けだけ残る

捧げる操作(祠での差し出し・焼き)と巻き戻しは実装済みです。
本編を待たずに確かめたいときは、画面右上の「確認用」から手で捧げると、日記が黒くなり、世界からその話が欠けるのが見られます。「祠をひらく」からページを焼く確認もできます。
